# Archived setup-process reference

The second reference video is **How I Build Every GT3 Car Setup in LMU V1.4 (3-Step System)** by SimRacing Arnout. It demonstrates an Aston Martin GT3 at Spa in LMU, not an iRacing calibration.

Read the [analysis](../../../research/setup-process-video/analysis.md) alongside the source video. Raw media and transcripts are kept outside this repository. The source URL is https://www.youtube.com/watch?v=JiVMUyE6aYU.

Useful anchors:

- 01:12: exploration of wing baselines and corresponding platform balance under comparable conditions.
- 10:40: a selected baseline with critical-corner stability constraints.
- 17:29: additional pace/rotation experiments while retaining earlier stability goals.

Apply the sequence as exploration, constraint checking, and refinement. Select the team's own representative situations; do not require Spa corners or full-throttle passage elsewhere. The demonstration groups some changes and includes driver execution differences, so it does not isolate every causal effect. Author-specific minimum-setting advice should stay a sourced hypothesis.

For iRacing limitations, read [iracing-feasibility.md](../../../research/iracing-feasibility.md); for collection integration, read [simhub-integration.md](../../../research/simhub-integration.md). Model/AI operations remain proposals in [design-draft.md](../../../docs/design-draft.md).
